# 🔧 מוסך – ניהול נהגים

אפליקציית PWA לניהול נהגים במוסך בזמן אמת.

---

## שלב 1 – הגדרת מסד הנתונים ב-Supabase

1. כנס ל-[supabase.com](https://supabase.com) לפרויקט `garage-drivers`
2. לחץ על **SQL Editor** בתפריט הצד
3. העתק את כל התוכן מהקובץ `supabase-setup.sql`
4. הדבק ולחץ **Run**

---

## שלב 2 – העלאה ל-GitHub

1. כנס ל-[github.com](https://github.com) וצור Repository חדש בשם `garage-drivers`
2. העלה את כל הקבצים

---

## שלב 3 – פריסה ב-Vercel (חינמי)

1. כנס ל-[vercel.com](https://vercel.com)
2. התחבר עם חשבון GitHub
3. לחץ **New Project** → בחר את `garage-drivers`
4. לחץ **Deploy**
5. תוך דקה תקבל כתובת כמו `garage-drivers.vercel.app`

---

## שלב 4 – התקנה על הטלפון (PWA)

### אייפון:
1. פתח Safari → כנס לכתובת האפליקציה
2. לחץ על כפתור השיתוף (מרובע עם חץ)
3. בחר **"הוסף למסך הבית"**

### אנדרואיד:
1. פתח Chrome → כנס לכתובת האפליקציה
2. לחץ על 3 הנקודות למעלה
3. בחר **"הוסף למסך הבית"**

---

## מבנה האפליקציה

```
src/
├── App.js              # ניתוב ראשי
├── lib/
│   └── supabase.js     # חיבור למסד נתונים + קבועים
├── pages/
│   ├── Login.js        # מסך כניסה
│   ├── Dashboard.js    # לוח בקרה לשולחים
│   └── DriverView.js   # מסך נהג
└── components/
    ├── NewTaskModal.js  # פתיחת משימה חדשה
    └── GarageCars.js   # ניהול רכבי מוסך
```
